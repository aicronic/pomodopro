# PomodoPro 🍅

A retro-styled Pomodoro timer Chrome extension with customizable settings.

## Features ✨

*   Customizable work, break, and long break durations.
*   Notifications to alert you when it's time to work or take a break.
*   Sounds to signal the start and end of sessions.
*   Auto-start next session option for continuous workflow.
*   Retro-styled interface.

## Usage 🚀

1.  Install the extension from the [Chrome Web Store](https://chromewebstore.google.com/detail/pomodopro/nabjbopanefafaamkcdjankbgeikfpla).
2.  Click the PomodoPro icon in your browser toolbar.
3.  Customize the work, break, and long break durations using the sliders.
4.  Enable or disable notifications and sounds using the toggles.
5.  Start the timer and focus on your work!
